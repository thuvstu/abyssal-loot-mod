# 試練・武器奥義アップデート

## 出撃条件

出撃前に8種類の呪印を0〜8枚選択できる。同種の重複は不可。

| 呪印 | 実戦効果 | 魂加算 |
|---|---|---:|
| 剛力 | 敵HP ×1.30 | +18% |
| 鋭牙 | 敵攻撃 ×1.22 | +16% |
| 疾風 | 敵移動 ×1.16 | +14% |
| 乱舞 | エリート出現率 ×1.90（上限90%） | +22% |
| 飢餓 | HP回復量 ×0.58 | +20% |
| 鈍痛 | 魂・奥義ゲージ獲得 ×0.70 | +16% |
| 注視 | 索敵・射撃開始距離 ×1.45 | +14% |
| 深淵 | 敵HP・攻撃・移動・索敵 ×1.10 | +26% |

呪印の魂倍率は加算式。全選択で **1 + 146 / 100 = 2.46**。
難易度・モード倍率の後に適用される。実績報酬は別計算で呪印倍率を掛けない。
初期HP・蘇生HPは回復量制限の対象外。戦闘回復・回復アイテム・休息・層移動の回復には飢餓が作用する。

`POST /api/expeditions` が選択条件をDBに記録し、その設定でエンジンを開始する。
`POST /api/runs` は出撃ID、英雄ID、職業、モード、難易度、呪印ID・枚数を照合する。
報酬は登録条件からサーバー側で再計算。重複呪印・不明ID・8枚超・属性の使い過ぎを拒否。
出撃行をトランザクション内でロックし、同じ結果の再送では戦績・魂・実績を重複加算しない。

戦闘自体はブラウザーで実行する。これは出撃条件の固定と二重処理防止であり、サーバー権威型戦闘シミュレーションや完全な不正対策ではない。

## 操作

- WASD / 方向キー：移動。スマホは左スティック。
- マウス / スマホ右スティック：照準。
- 左クリック / J：攻撃。近接長押し・解放：溜め重撃。
- Shift / Space：回避。
- Q：職業の必殺技。
- **E：武器固有奥義**。スマホには独立した奥義ボタン。
- G：近くの装備を拾う（接触でも自動）。
- F：鍛造。開いている間は停止。
- Esc / P：一時停止・属性配分。配分は停止中のみ。

装備比較画面での E は装備決定。戦闘中の E と同時には動作しない。

## 武器奥義

与えた実ダメージ・受けたダメージでゲージを蓄積する。オーバーキル分、奥義自身、環境罠・二次反応ではゲージを水増ししない。

- 剣：月牙斬 — 3発の貫通斬撃波
- 斧：大地砕き — 大範囲爆発・強ノックバック
- 槍：竜殺し — 無敵突進・経路上の敵に一度ずつ命中
- 杖：星辰大爆裂 — 0.6秒の着弾予兆後、敵の位置に隕石
- 弓：疾風連雨 — 発射ごとに再照準する13連射
- 短剣：影襲 — 敵の背後へ瞬移・単体強襲
- 槌：崩壊スマッシュ — 単体極大・周囲への感電・スタン
- 刀：心無一刀 — 周囲を一閃・敵弾消去
- 鎌：冥府の収穫 — 瀕死の敵に追加威力
- 拳套：六連震掌 — 6段の衝撃
- 輪刃：輪廻乱舞 — 16枚の貫通輪刃
- 魔導書：禁書・虚空葬 — 時間差爆縮・脆弱付与

武器交換に応じて奥義が変化する。発動後の予約攻撃は発動時の武器・威力を使う。

## 戦術敵と罠

- 鉄壁の護衛兵（4F〜）：前方120°ではダメージ30%、側面・背面では135%。向きの転換に時間がかかるため、回り込みが有効。
- 骸骨の蘇生師（6F〜）：中距離を維持し、朽ちた兵を召喚。生存する子の数に上限がある。
- 呪われた召喚門（7F〜）：移動せず、破壊されるまで増援を出す。各門の増援は最大6体、画面の敵は最大48体。
- 針罠・岩罠（5F〜）：敵味方共通の感圧罠。一度だけ作動。予兆後に範囲ダメージ・吹き飛ばし。回避で避ける、敵を誘う、どちらも可能。

召喚門の破壊は戦績に保存され、実績「門を断つ者」を解除する。

## 属性ポイント

レベルアップごとに1点。初期レベルが高い場合も `現在Lv - 1` 点を所持。
属性配分は冒険ごとの育成で、次の冒険ではリセット。

- 剛力：攻撃力 +3% / 点
- 韻律：攻撃速度 +2% / 点
- 敏捷：移動 +1.5%、回避短縮 +1% / 点
- 忍耐：最大HP +4% / 点（HP回復ではない）
- 幸運：運 +7、素材獲得量 +4% / 点

素材倍率の端数もシード付き抽選に反映し、1個ドロップでも+4%が無駄にならない。

## 回帰テスト

純粋なルール・模擬Canvas上の戦闘：

```sh
npm exec tsc -- --target es2022 --module commonjs --moduleResolution node --lib es2022,dom --skipLibCheck --esModuleInterop --outDir /tmp/abyss-test-build --rootDir src/game src/game/engine.ts src/game/run-rules.ts
node --test tests/abyss-regression.cjs
```

稼働中のプレビューに対するAPI・PC・モバイル操作：

```sh
npx playwright install --with-deps chromium
npx playwright test
```

API試験は専用のQA英雄を作り、終了後にDrizzleで削除する。既存の英雄・戦績を削除しない。
ブラウザーでは呪印選択→登録→属性配分→鍛造→撤退→保存まで確認する。

スキーマ変更は環境起動後に `npx drizzle-kit push` で適用する。ビルドの成功だけではDB列の存在や実戦挙動を保証しない。
