状態の表記:
- **済**: 原作と同等に実装済み (実ビルド・ユニットテストで確認)
- **部分**: 名前・数値・挙動の一部のみ
- **未**: Mod に該当する実装が見当たらない (grep で確認)
- **要判断**: 実装方針 (Minecraft 向けに何を残すか) をユーザーに決めてほしい

検証の前提: Java の実機確認 (`runClient` での目視・操作) は未実施。CI (`./gradlew build test`) は通過している。
